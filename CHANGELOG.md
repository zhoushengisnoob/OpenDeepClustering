# Changelog

All notable changes to OpenDeepClustering are recorded here. The project follows semantic versioning from v0.2.0 onward.

## [Unreleased]

### Added

- `global_rms` normalization, dividing the dataset by one global constant so `mean(x^2)` is 1 across the dataset while per-sample magnitude differences survive. DEC and IDEC reference configurations now use it.
- `docs/benchmarks/dec-idec-normalization-2026-10-30.md` records the defect and the gold-standard validation that found it, and `docs/benchmarks/dec-idec-globalrms-2026-10-30.md` is the new five-seed reference.
- `docs/architecture/dataset-contract.md` specifies dataset identity, the closed set of preprocessing recipes, the split boundary and the provenance a result must carry.
- `docs/benchmarks/comparison.md`, a method comparison grouped by protocol key (dataset digests, counts, split, preprocessing) so only configuration-matched runs sit in one table. Generated by `tools/build_comparison_table.py` from the committed records and verified in CI.
- `examples/compare_methods.py`, a CPU example running all five estimators over three seeds on two contrasting datasets, each against a KMeans-on-raw-input floor. Runs in CI.
- `docs/benchmarks/records/mnist-5seed-dec-idec-2026-09-15.json` commits the per-seed metrics for the DEC/IDEC five-seed reference.
- `metrics.embedding_effective_rank` for detecting representation collapse, with `DeepCluster` recording `effective_rank` and `mean_dim_std` per clustering pass and exposing `effective_rank_` after fitting.
- Benchmark results carry a per-run `effective_rank` field for estimators that expose an `embedding_` attribute.
- Quality-floor tests for `DeepCluster`: an effective-rank floor across multiple alternating rounds and an accuracy floor relative to KMeans on the raw input. A strict-`xfail` test pins the defective image path and will fail once that backbone is repaired.
- `docs/benchmarks/deepcluster-collapse-2026-10-28.md` isolates the cause of DeepCluster's near-chance MNIST accuracy and bounds what the identified repairs achieve.
- `docs/benchmarks/three-pattern-mnist-2026-09-18.md` publishes the audited 20-seed MNIST baselines for `AutoencoderKMeans`, `VaDE` and `DeepCluster`, with medians and 95% confidence intervals.
- `docs/benchmarks/vade-variance-2026-10-29.md` characterises VaDE's seed variance from training-state evidence, with six deterministic tests covering mixture parameter shapes, responsibility normalisation, covariance and weight bounds, fitted mixture state and restart reproducibility.
- `docs/benchmarks/records/mnist-20seed-2026-09-18.json` commits the per-seed metrics for that batch, with `tools/audit_benchmark_batch.py` to build such a record from a run directory and `tools/report_benchmark_record.py --check` to regenerate and verify every reported aggregate without server access.

### Changed

- **DEC and IDEC MNIST accuracy rose from 0.7788 and 0.7938 to 0.8616 ± 0.0094 and 0.8771 ± 0.0089**, reaching published level, and seed variance fell by about two thirds. The previous `dec` normalization divided each sample by its own root mean square, discarding per-sample magnitude; on MNIST that carries class information, since mean per-sample RMS ranges from 64 for digit 1 to 98 for digit 0.
- `normalization` is a closed set (`global_rms`, `dec`, `unit`, `none`). An unrecognised value now raises; previously it was silently ignored and the run trained on unnormalized data.
- `tools/audit_benchmark_batch.py` takes the expected seed count as `--expected-seeds` instead of assuming 20, so a five-seed batch is not reported as incomplete.
- Quoted DEC and IDEC deviations switched to sample standard deviations (ACC 0.0313 and 0.0327) for consistency with the other records; the 2026-09-15 page keeps its published population figures and now states which convention it uses.
- Benchmark `schema_version` raised from 1 to 2 for the added `effective_rank` field.
- `VaDE`'s documented status changed from architecture reference to validated with stated instability: its 20-seed MNIST accuracy of 0.7158 ± 0.0454 spans a range of 0.149, so figures must be quoted with the seed count and confidence interval. The spread originates in the pretrained embedding the mixture is initialised on, not in the mixture fit or component collapse.
- `DeepCluster`'s documented status changed from architecture reference to known defect: its 20-seed MNIST accuracy of 0.2040 ± 0.0140 is below the 0.5342 reached by KMeans on raw pixels, so it must not be used as a baseline or correctness oracle.

## [0.2.0] - 2026-09-15

### Added

- A scikit-learn-style estimator contract with shared data validation, fit state, callbacks, checkpoints and deterministic seed control.
- Paper-traceable DEC and IDEC implementations with full-dataset target updates, assignment-change stopping and reference MNIST configurations.
- Architecture-reference implementations for Autoencoder + KMeans, DeepCluster and VaDE, covering the Survey's multi-stage, iterative and generative patterns alongside the simultaneous DEC/IDEC family.
- A shared YAML-driven benchmark CLI with configuration, environment, Git revision, data checksum, metric, duration and stop-reason capture.
- Mathematical component tests, estimator compatibility checks, end-to-end benchmark tests and Python 3.10/3.11 CI.
- Versioned method specifications, architecture reviews, provenance records, benchmark reports and a MkDocs documentation site.
- BSD-2-Clause licensing, citation metadata and reproducible source/wheel package validation.

### Changed

- Package dependencies and archive contents are now explicitly bounded and validated.
- Legacy scripts remain available as historical reproduction material while the supported Python API and CLI share one estimator core.

### Evidence

- Issues #2–#8 and their linked pull requests contain the implementation history and review boundary.
- `docs/benchmarks/mnist-reference-2026-09-15.md` records the five-seed DEC/IDEC GPU baseline.
- `docs/benchmarks/four-pattern-smoke-2026-09-15.md` records the four-pattern server smoke validation.
